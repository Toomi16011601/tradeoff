# Security

Tradeoff executes the Python callback you supply. Treat it as ordinary local Python execution, and audit simulation entry points before using them. Generated reports are offline; they have no telemetry or built-in broker connection.

The tool has no account service or built-in project upload. Local data import uses the Python standard library and reads only the files you select. Installing dependencies can use your package index; imported strategy code and any agent you connect have their own behavior. A cloud coding agent may transmit the tool output or files you give it to its provider. Local installation alone does not make that agent offline.

Importing a strategy or executing a generated pytest can run arbitrary Python. These operations are not sandboxed: use only trusted simulation code, keep live trading credentials out of its environment, and inspect externally supplied callback references before replay. The bundled public-case loader verifies pinned source hashes and selects simulation code; upstream API-fetching entry points are not executed.

Native input preflight happens after import. It inspects bounded direct data/global references without running strategy methods, but it cannot prevent import side effects, inspect arbitrary helpers or verify the meaning of initialized data. Explicit acknowledgements of zero volume or optional `None` globals record limitations; they are not security exceptions or evidence of complete strategy validation.

HTML, JSON reports and replay fixtures retain complete simulation inputs and configuration. HTML embeds its JSON even when a section is collapsed. Treat these exports as private until reviewed. Recognized credential/contact/account fields, credential formats and home-directory paths are rejected before execution or export, without silently modifying hashes. Ordinary callback exception messages are omitted; `ExecutionUnavailable` is an explicit opt-in for a safe limitation message. These checks cannot identify every secret, personal identifier or proprietary strategy. Use synthetic or deliberately sanitized data for shared examples; hashes do not encrypt data.

`lab` and `audit` offer **opt-in private diagnostics** through `--diagnostics PRIVATE_FILE`. These raw tracebacks can include private exception messages, source lines and filesystem paths; no local-variable dump is captured. The CLI requires a new file outside the portable output directory. Creation is exclusive, refuses existing files and final-component symlinks, and requests mode `0600` on POSIX systems; the parent directory must already exist. Raw diagnostics are not embedded in portable reports or stdout. Keep them outside shared repositories and review them before sending them to a person or agent. The Python `local_diagnostics(path)` API leaves selection of a separate private destination to its caller.

Declared companion inputs must resolve inside the current project. Exports store their relative paths and SHA-256 hashes, not their contents; those names and hashes may themselves reveal project structure. Replay verifies the selected files before resolving the runner and executing it. This does not constrain what arbitrary imported Python can read. Source-file hashes and known runtime versions record provenance without capturing every helper or bundling a reproducible environment. Source changes remain allowed during strategy repair.

The preview binds only to `127.0.0.1` and accepts its exact host/port and same origin. It serves known report artifacts only, rejects symlinks and directory listings, and disables external resources through a content security policy. Secure filesystem traversal is supported on macOS/Linux; other platforms fail closed. Opening generated HTML directly does not provide the HTTP preview's security headers. Do not expose the preview through a public tunnel or use it to host arbitrary downloaded HTML.

Source distributions strip local filesystem ownership and timestamps. Internal session notes, generated private artifacts, credential files and stale builds are excluded from publication. The public GitHub hosting account and its activity are inherently visible. Third-party author names and license notices are retained as required attribution.

Report injection or path traversal issues with a minimal synthetic reproducer. Do not include secrets in public issue reports. Use the repository's private vulnerability reporting feature if available. If no private reporting channel is available, open an issue requesting one without including exploit details, private data or credentials.

Fixture hashes detect changes to content, not trustworthiness of code or origin. Future dependencies and financial losses are research/debugging concerns rather than security guarantees.
